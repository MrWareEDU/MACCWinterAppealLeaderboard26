Winter Appeal Leaderboard

One-time setup guide — takes about 10 minutes

View Leaderboard

This page walks through the one-time technical setup. Once it is done, care teachers submit box counts via a simple Google Form — no spreadsheet access, no logins, works on any phone or computer.

You will need: a Google account (the school Google account is fine), and access to this GitHub repository.

1
Create the Google Form

Go to forms.google.com and click the blank form (+). Name it Winter Appeal 2026 — Box Count Update.

Add exactly two questions:

  1. Question 1 — Care Group
    Type: Dropdown. Add one option per care group (e.g. 9A, 9B, 10A, 10B, 11A…). Mark as required.
  2. Question 2 — Total boxes collected so far
    Type: Short answer. Click the three-dot menu on the question and choose Response validation → Number → Greater than or equal to → 0. Mark as required.
Teachers submit the running total, not just boxes added since last time. The leaderboard always shows the most recent submission per care group, so totals are always accurate.
2
Link the form to a Google Sheet

Responses need to land in a Sheet so the leaderboard can read them.

  1. In the Form, click the Responses tab at the top
  2. Click the green Sheets icon (or the three-dot menu → Select response destination)
  3. Choose Create a new spreadsheet and name it Winter Appeal 2026 — Data
  4. Click Create

Google will open the Sheet. It will have one tab called Form Responses 1 with three columns: Timestamp, Care Group, and Total boxes collected so far.

Do not rename or move this tab — the formula in the next step depends on it.
3
Create the Leaderboard tab

The leaderboard needs a clean tab showing one row per care group with the most recent box count. Add a new tab to the Sheet:

  1. Click the + button at the bottom left of the Sheet to add a new tab
  2. Double-click the new tab and rename it Leaderboard
  3. In row 1, type these three headings exactly: Care Group (A1), Year Group (B1), Boxes (C1)
  4. From row 2 down, fill in column A and B with your care groups and year groups — one row per group
Care GroupYear GroupBoxes
9AYear 9(formula)
9BYear 9(formula)
10AYear 10(formula)
10BYear 10(formula)
11AYear 11(formula)

In cell C2, paste this formula exactly:

=IFERROR(QUERY('Form Responses 1'!A:C,"SELECT C WHERE B='"&A2&"' ORDER BY A DESC LIMIT 1",0),0)

Then drag the formula down to fill C3, C4, and so on — one cell per care group row.

This formula finds the most recent form submission for each care group and shows that number. If no submission has been made yet, it shows 0.
4
Publish the Leaderboard tab to the web

The leaderboard app reads the Sheet as a public file. Publishing it does not give anyone edit access — it only makes the data readable by the leaderboard page.

  1. Make sure you are on the Leaderboard tab
  2. Click File → Share → Publish to web
  3. Under the first dropdown, select Leaderboard
  4. Under the second dropdown, select Comma-separated values (.csv)
  5. Click Publish, then confirm with OK
Leave the Sheet open — you need the Sheet ID and tab GID in the next step.
5
Copy the Sheet ID and tab GID

With the Leaderboard tab open, look at the URL in your browser. It contains two values you need:

docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit#gid=839652104
  • The long string after /d/ and before /edit — this is the Sheet ID
  • The number after gid= — this is the tab GID for the Leaderboard tab

Copy both values. You will paste them into config.js in the next step.

6
Update config.js

Open the file js/config.js in this repository and update the two lines shown below:

SHEET_ID: '1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms', SHEET_GID: '839652104',

Replace both values with your own Sheet ID and Leaderboard tab GID from the previous step. Save the file and commit the change to the repository.

The GID must point to the Leaderboard tab — not the Form Responses tab. If the leaderboard page shows no data, this is the most likely cause.
7
Enable GitHub Pages

This publishes the leaderboard as a live website at a permanent URL.

  1. Go to the repository on GitHub
  2. Click Settings (top menu)
  3. In the left sidebar, click Pages
  4. Under Source, select Deploy from a branch
  5. Choose the main branch and the / (root) folder
  6. Click Save

After a minute or two, GitHub will show the live URL at the top of the Pages settings — something like https://mrwareedu.github.io/maccwinterappealleaderboard26/.

This URL is the public leaderboard. Share it with the AV team for assembly display. It requires no login and works on any device.
8
Share the form with care teachers

Care teachers submit box counts through the Google Form — no Sheet access needed.

  1. Open the Google Form
  2. Click the Send button (top right)
  3. Click the link icon to get the shareable URL. Tick Shorten URL for a cleaner link
  4. Share the link via email, staff portal, or print it as a QR code

To get a QR code: click the three-dot menu next to Send, or use any free QR code generator with the form URL. Print and post it in the staffroom or on each classroom door.

Teachers can submit as many times as they like. Only the most recent submission per care group is used — so submitting a corrected total simply replaces the previous one on the leaderboard.

The form does not require a Google account by default. If you want to restrict submissions to school accounts only, open the form settings and enable Restrict to users in your organisation.

Setup complete

The leaderboard is live. Care teachers submit counts via the Google Form, and the leaderboard updates within 30 seconds.
Open the leaderboard to confirm everything is working.
