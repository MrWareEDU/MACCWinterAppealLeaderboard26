Winter Appeal Leaderboard

One-time setup guide — takes about 10 minutes

View Leaderboard

This page walks through the one-time technical setup. Once it is done, any staff member can update the leaderboard by simply editing a Google Sheet — no technical knowledge required.

You will need: a Google account (the school Google account is fine), and access to this GitHub repository.

1
Create the Google Sheet

Go to sheets.google.com and create a new spreadsheet. Name it something clear, such as Winter Appeal 2026 — Leaderboard.

Set up the first row as column headings, exactly as shown below. Spelling and capitalisation must match.

Column A
Care Group
e.g. 9A, 10C, 11B
Column B
Year Group
e.g. Year 9, Year 10
Column C
Boxes
Numbers only — e.g. 14

Then add a row for each Care Group. Example:

Care Group Year Group Boxes
9AYear 90
9BYear 90
10AYear 100
10BYear 100
11AYear 110
Start all box counts at 0. The leaderboard will update as staff enter real numbers during the appeal.

To protect the structure, select columns A and B, right-click, choose Protect range, and restrict editing to yourself. This prevents accidental changes to names.

2
Publish the Sheet to the web

The leaderboard reads the Sheet as a public file. You need to publish it — this does not share the Sheet with anyone or give anyone edit access. It only makes the data readable by the leaderboard page.

  1. In the Sheet, click File in the top menu
  2. Click Share, then Publish to web
  3. Under the first dropdown, select Sheet1 (or the name of your tab)
  4. Under the second dropdown, select Comma-separated values (.csv)
  5. Click Publish, then confirm with OK
Leave the page open — you will need the Sheet ID in the next step.
3
Copy the Sheet ID

Look at the URL in your browser while the Sheet is open. The Sheet ID is the long string of letters and numbers between /d/ and /edit.

docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit#gid=0

Copy just the highlighted part. You will paste it in the next step.

4
Paste the Sheet ID into config.js

Open the file js/config.js in this repository. Find the line that reads:

SHEET_ID: 'YOUR_GOOGLE_SHEET_ID_HERE',

Replace YOUR_GOOGLE_SHEET_ID_HERE with the ID you copied. It should look like:

SHEET_ID: '1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms',

Save the file and commit the change to the repository.

5
Enable GitHub Pages

This publishes the leaderboard as a live website at a permanent URL.

  1. Go to the repository on GitHub
  2. Click Settings (top menu)
  3. In the left sidebar, click Pages
  4. Under Source, select Deploy from a branch
  5. Choose the main branch and the / (root) folder
  6. Click Save

After a minute or two, GitHub will show the public URL at the top of the Pages settings. It will look like: https://mrwareedu.github.io/maccwinterappealleaderboard26/

Share this URL with staff for the admin sheet link, and with the AV team for the assembly display. The same URL works for both — the page is viewable by anyone.
6
Share the Google Sheet with admin staff

Anyone who needs to update box counts needs edit access to the Google Sheet — not the website.

  1. In the Sheet, click the Share button (top right)
  2. Enter the email address of each staff member who will update scores
  3. Set their permission to Editor
  4. Click Send

They will receive an email with a link to the Sheet. Bookmark it, or find it any time in Google Drive. To update a score, they simply click the number in column C and type the new total.

Changes appear on the leaderboard within 30 seconds — no button to press, no page to reload.

Setup complete

The leaderboard is live. Share the GitHub Pages URL with staff and the assembly team.
To update scores at any time, edit column C in the Google Sheet.
Open the leaderboard to confirm everything is working.
